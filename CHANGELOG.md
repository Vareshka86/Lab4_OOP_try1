# История версий

Здесь записано, что было сделано в каждой версии лабораторной работы.
Каждой версии в git соответствует метка (тег) с тем же именем.
Новые версии добавляются сверху.

## v0.1 — 2026-10-05

Выполнена часть 1 из 4: иерархия из трёх уровней SmartDevice → PoweredDevice → LightBulb и учёт
энергии (вариант 5 — устройства умного дома).

### Сделано

- `SmartDevice` — абстрактный базовый класс: имя, состояние, чисто виртуальные `turnOn()`, `turnOff()`,
  `getStatus()`, виртуальный деструктор, статический счётчик существующих устройств. Копирование до
  части 4 запрещено (`= delete`).
- `PoweredDevice` — промежуточный абстрактный класс: номинальная мощность, `turnOn()` и `turnOff()` с
  учётом энергии, виртуальная `getPowerUsage()` с реализацией по умолчанию. Статические члены: общий
  счётчик кВт·ч всех устройств и модельное время; статические функции `getTotalEnergyConsumed()`,
  `getClockHours()`, `advanceClock()`.
- `LightBulb` — конкретный класс: яркость и цвет, переопределения `getPowerUsage()` и `getStatus()`;
  при смене яркости включённой лампы энергия до изменения засчитывается по старой мощности; деструктор
  выключает включённую лампу.
- Отдельный файл с тестами `tests.cpp`: создание объектов, полиморфные вызовы, учёт энергии и
  статические члены, исключения при неверных параметрах, виртуальный деструктор.
- Диаграмма классов `uml/SmartHome.puml` (картинка `uml/SmartHome.png`), страница документации
  `pages/part1.md`, README.

### Проверено

- Сборка `g++ -std=c++14 -Wall -Wextra -pedantic -static` (g++ 16.2.0) — без ошибок и предупреждений.
- Тесты программы — 27 проверок из 27.
- Отдельная тестовая программа — 16 проверок из 16: свойства типов (абстрактные классы, виртуальный
  деструктор, запрет копирования), дробные интервалы времени, смена яркости у выключенной и включённой
  лампы, энергия при уничтожении включённой лампы, удаление через указатель на PoweredDevice,
  исключение в конструкторе.
- Doxygen 1.18.0 собирает документацию без предупреждений; диаграмма — PlantUML 1.2026.8.
